TD2 - Algorithmes de Tri

pour ne pas avoir à créer le fichier directement dans le main, j'ai préféré faire 
un fichier binaire à part que l'on peut simplement appeler pendant l'execution du main.

Instructions

1. Compiler et exécuter le generate_data.c
Cela crée un fichier data.bin contenant les n entiers aléatoires.

2. Compiler le programme principal (tous les autres fichiers.c)

Pour modifier le nombre d'éléments à générer, changer la valeur de n dans generate_data.c
